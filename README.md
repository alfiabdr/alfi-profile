# Personal Portfolio / CV Landing Page

## Files
- `index.html` — page content
- `style.css` — design and responsive layout
- `script.js` — smooth scrolling + navigation behavior
- `cv.pdf` — add your real CV here

## Quick edit
Open `index.html` and search/replace:
- `Your Name`
- `yourname`
- `your.email@example.com`
- LinkedIn / GitHub URLs
- Experience
- Certifications
- Projects
- Skills

## Run locally
Just double-click `index.html`, or use VS Code Live Server.

## Deploy
This static site can be deployed to GitHub Pages, Cloudflare Pages, Netlify, Vercel, or any normal web server.
